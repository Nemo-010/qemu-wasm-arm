The page mounts the firmware into Emscripten's virtual filesystem and hands it to QEMU at runtime, so nothing is baked into the build.

Why this matters

A cycle-level ARM machine in the browser means firmware can be run and inspected where it was written. Neucom Sphere would call that the Electrosphere doing its job.
