qemu-wasm-arm

qemu-system-arm compiled to WebAssembly. It runs a real Zephyr application on an emulated mps2-an385 and draws on an emulated SSD1306, so the panel below is the controller's own memory rather than a screenshot of a rendered surface.

SSD1306 · 128 × 64

Read back from the emulated controller's GDDRAM over QOM after each frame. Nothing here is inferred from what the guest says it drew.

The firmware is mounted into Emscripten's virtual filesystem at runtime, so a new build does not need a relink.

Isolation

This build uses pthreads, so it needs SharedArrayBuffer, which browsers only give to a cross-origin isolated page. GitHub Pages cannot send the headers, so a service worker adds them and the page reloads once.

The two bugs that mattered

wasm32 TCG passed guest addresses to the MMU helpers with stray high bits.
  0xE000E018 became 0x1E000E018, so the access was rejected and Zephyr
  surfaced a precise data bus fault the first time it read the timer.

mps2.c marks its first two I2C buses full, so -device on them fails with
  "bus not found". The machine now creates the panel on the first shield
  connector itself.

Both are written up in patches/README.md and build.sh alongside the rest of the build workarounds.
